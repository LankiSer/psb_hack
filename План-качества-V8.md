1. **Контроль** — сохранить ZIP + хеш + балл каждой попытки. Нужен независимый размеченный набор (демо — только регрессия).
2. **Документ и редакция** — явный номер важнее похожего имени; дата → действующая редакция; при неоднозначности — уточнить.
3. **Числа и условия** — единица + роль (рабочие/календарные дни, деньги); числительные словами; границы N±1.
4. **Ответ из проверенных утверждений** — каждое число/срок/обязанность с привязкой к источнику; неверный кусок выкидывать, не оставлять.
5. **Поиск** — чинить только по измеренному дефициту оснований, не «на всякий случай».

На платформе: один смысловой блок за сабмит. Сравнивать с контролем, не гнаться за максимумом одной попытки.
